Multi-Agent Memory Hub dashboard

A read-only web dashboard for the hub's memory graph that runs only on your machine. The demo below runs on fictional sample data.

What the demo shows

  • Home: live counts of memories, connections, agents working now and sessions, with the banner saying the data is fictional.
  • Memory Graph: a 3D view of the graph, with search.
  • The Room: one card per agent, with presence.
  • Timeline: sessions grouped by day.
  • Explorer: every node in a sortable, filterable table.
  • Privacy: what the secret filter handles and what it does not.

Notes

  • The dashboard is read-only and runs only on your machine: the API listens on 127.0.0.1 only and answers GET and HEAD only.
  • The demo uses room dashboard-api --demo, which serves a fictional sample set from a temporary folder and never reads your real memory.
  • This page is a recording of the dashboard, not a live hosted app.
